# AlbumWall —— 简单的基于博客内容的Typecho相册墙

把指定标签下的文章的图片按文章聚合成一面相册墙。点开后相册原地展示，具备流畅的交互动画！
让你像写博客或者游记一样轻松上传照片，至于不必单独维护相册页面，整理就交给它！

eg：整理所有包含tag为摄影的博客/日记/游记等等乱七八糟的文章，汇总为照片墙。

## 特性

- **多标签聚合**：标签可多选，命中任意一个标签的文章都会进相册；一篇文章同时挂着多个标签时只出现一次
- **零建表、零写库**：相册是对既有文章的一种视图，仅使用 Typecho 现有的数据：页面标题、固定链接、日期、文章内容
- **不注册路由**：基于 Typecho 原生，提供插件与一份独立页面模板；
- **服务端渲染**：首屏不依赖 JS，禁用 JS 也能正常看到相册网格；
- **Jasmine优化**：Jasmine 自动适配配色与CSS，其他主题包含回退；
- **遵守 `prefers-reduced-motion`**：系统开了减少动态效果时，动画整体退化为瞬间完成；
- **兼容 pjax**：用 pjax 进出相册页不会残留浮层，也不会丢样式。

## 安装

1. 把 `AlbumWall` 目录放进 `usr/plugins/`；
2. 后台 → 控制台 → 插件 → 启用 **AlbumWall**；
3. 把插件目录下 `theme/page-album.php` 复制到当前主题目录（例如 `usr/themes/Jasmine/`）；
4. 后台 → 管理 → 独立页面 → 新增，其他内容自定，「自定义模板」选 **相册**，发布。

## 配置项

| 项 | 默认 | 说明 |
|---|---|---|
| 相册标签 | `Photo` | 哪些标签下的文章会被聚合成相册，**可多选**。勾选框列出站上已有标签及各自文章数，基于**缩略名**不是显示名 |
| 页面标题 | `相册` | 独立页面自身有标题时以页面标题为准 |
| 相册排序 | 发布时间（新的在前） | 另可选旧的在先、按标题 |
| 没有图片的文章 | 跳过 | 也可以选择显示成占位卡片 |

封面一律取正文第一张图。正文里一张图都没有时，由「没有图片的文章」这项决定是跳过还是留一张占位卡片。想在封面上用别的图，就把那张图放到正文最前面。

一个标签都不勾的话，按留白处理，不会自动把默认标签塞回来。

## 从 1.0.0 升级

1.0.0 存的是单个标签（`tagSlug`），1.1.0 起改成标签数组（`tagSlugs`）。老配置会被自动读出来当成「只勾了那一个」，不用重新配；保存一次之后新配置才真正落库，旧键会原样留着，回退到 1.0.0 也不会丢设置。


## 目录结构

```
AlbumWall/
├── Plugin.php              # 插件入口：配置表单、激活提示
├── Query.php               # 取数：按标签查文章、算封面和图片列表
├── Extract.php             # 从正文里提取图片地址（markdown + HTML 两种写法）
├── View.php                # 前台数据与格式化，模板只负责摆位置
├── Theme.php               # 配色档位判定（Jasmine / 其它主题）
├── Chrome.php              # 主题外壳探测与拼装
├── template/
│   ├── album.php           # 相册墙主体：网格 + 浮层 + 脚本加载器
│   ├── shell-header.php    # 主题没有可用外壳时的兜底页头
│   └── shell-footer.php    # 兜底页尾
├── theme/
│   └── page-album.php      # 复制到主题目录的独立页面模板
└── static/
    ├── album.css
    └── album.js            # 展开动画
```
